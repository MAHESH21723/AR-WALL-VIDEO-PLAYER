# HoloWall - AR Video

<p align="center"><img src="Docs/icon-512.png" width="160" alt="HoloWall icon"></p>

**HoloWall** is an Android AR app that detects walls (and floors) with ARCore and places a video "hologram" on them. Play the built-in holographic clips with the green background removed, or pick any video from your gallery and show it on a glowing AR screen.

Made by **Maheshwaran** - [github.com/MAHESH21723](https://github.com/MAHESH21723)

![Hologram clips](Docs/holograms-preview.png)

## Features

- ARCore plane detection, vertical and horizontal, walls preferred; subtle grid visualizer you can hide.
- Placement reticle snaps to the plane under the screen centre. Tap to place or move the screen.
- Pinch to scale (clamped), twist to rotate, Lock to freeze the screen, Reset to remove it.
- Chroma-key shader (hand-written URP HLSL): key colour, similarity, smoothness, spill suppression, scanlines, flicker, rim glow and optional cyan tint.
- Two display modes: **Hologram** (green removed) and **Screen** (normal video with a thin glowing frame).
- Four built-in looping clips: Globe, Logo, Reactor, Radar. Previous / play-pause / next controls and mute.
- **Pick video** opens the phone gallery (NativeGallery) and plays your video on the placed screen.
- Friendly messages if ARCore is missing, unsupported, or the camera permission is denied.
- Portrait UI with safe-area handling, cyan/violet on navy theme.

## How to use

1. Start the app and tap **Start**, then move your phone slowly to scan a wall.
2. Aim at the wall and tap to place the hologram screen.
3. Pinch to resize, tap another spot to move it, or use **Pick video** to play your own clip.

## Requirements

- An Android phone that supports ARCore (Android 8.0 / API 26 or newer, ARM64) with Google Play Services for AR.
- To build: Unity 6000.6.2f1 with the Android Build Support module (SDK, NDK, OpenJDK).

## Build (headless)

```powershell
& "<Unity 6000.6.2f1>\Editor\Unity.exe" -batchmode -nographics --burst-disable-compilation -quit `
  -buildTarget Android -projectPath . -logFile Logs\build.log `
  -executeMethod HoloWall.Editor.HoloWallBuild.BuildAndroid
```

The APK is written to `Builds/Android/HoloWall-<version>.apk` (debug signed, good for sideloading). `HoloWallBuild.SetupProject` can be run alone to regenerate the scene, materials, TMP font, icons and player settings.

## Project structure

```
Assets/HoloWall/Scripts    runtime code (namespace HoloWall)
Assets/HoloWall/Shaders    chroma-key, reticle and plane-grid URP shaders
Assets/HoloWall/Editor     HoloWallBuild (setup + build) and scene/UI builder
Assets/HoloWall/Fonts      Rajdhani-Bold + OFL text
Assets/HoloWall/Icon       app icon and logo
Assets/StreamingAssets/Holograms   built-in hologram clips (green background)
Tools/Media                scripts that generate the clips and icons
Docs                       images used in this README
```
